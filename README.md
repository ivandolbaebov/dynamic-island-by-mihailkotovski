# Dynamic Island — настраиваемое положение и горячие клавиши

Исходный проект: https://github.com/mihailkotovski/DynamicIsland

Основа этой версии — коммит `e88564911f63107771122b4feeff3c57169975e4`.
Сохранены исходные функции музыки, таймера, громкости и уведомлений.

## Запуск

1. Закрой прежний Dynamic Island через его меню. Две версии одновременно не запускаются.
2. Помести новый `DynamicIsland.exe` в постоянную папку и запусти.
3. Если использовал автозапуск, выключи его в старой программе перед заменой и включи в новой.
4. Настройки доступны по правому клику на остров → «Положение и горячие клавиши».
   Их также можно открыть через значок острова в области уведомлений Windows.

Для готового exe не нужны Python, Visual Studio или установленный .NET.
Поддерживаются 64-битные Windows 10 версии 2004 и новее и Windows 11.

## Управление по умолчанию

| Действие | Результат |
| --- | --- |
| Ctrl + Alt + D | Переключить «верхний центр ↔ сохранённое положение» |
| Ctrl + Alt + H | Полностью скрыть или показать остров |
| Ctrl + перетаскивание левой кнопкой | Переместить остров и сохранить новое место |
| Левый клик по значку в трее | Показать остров |
| Правый клик по значку в трее | Показать, скрыть, переключить положение, открыть настройки или выйти |

Нажатия для переключения положения выполняются отдельно: первое переносит остров,
второе возвращает его в центр. Быстрый двойной клик не нужен. Удержание сочетания не вызывает повторных переключений.
Скрытие не останавливает музыку или таймер. Ручное скрытие сохраняется после перезапуска;
если острова не видно, верни его через значок в трее или Ctrl + Alt + H.

## Два режима

- **Поверх окон.** Режим по умолчанию, высота рабочего пространства не меняется.
- **Отдельная полоса сверху.** Обычные развёрнутые окна располагаются ниже острова.
  Высота полосы регулируется от 46 до 120 логических пикселей с учётом масштаба Windows.
  При переносе в сохранённое место, скрытии, переходе в полноэкранное приложение или выходе полоса освобождается.
  При возврате в центр полоса снова включается.

В настройках есть готовые положения и ползунки точной настройки. Перемещение ограничено
главным экраном и учитывает размер раскрытого плеера. Это сохраняет управление доступным после изменения разрешения или масштаба.
Настройки автоматически записываются в `%LOCALAPPDATA%\DynamicIsland\settings.json`.

В полях горячих клавиш нажми желаемое сочетание с Ctrl, Alt или Win. Одинаковые сочетания,
обычный ввод без модификаторов и F12 не допускаются. Если сочетание уже занято Windows
или другой программой, сохранение покажет ошибку. Пока открыто окно настроек, глобальные
хоткеи острова приостановлены, чтобы их можно было записать в поле.

## Сборка из исходников

На Windows нужен только .NET 8 SDK, без дополнительных NuGet-пакетов приложения.
Открой терминал в папке `DynamicIsland` и выполни:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -p:Version=1.0.0-layout.1 -o publish
```

Готовый файл появится в `publish\DynamicIsland.exe`.
Для сборки из Linux дополнительно используется `-p:EnableWindowsTargeting=true`.

## Проверка

Сборка Windows x64 выполнена; отдельно прошли 16 проверок расчёта положения,
ограничений DPI, восстановления настроек и сериализации. Архив включает проверочный
консольный проект `layout-checks`, который не зависит от WPF и сторонних пакетов:

```powershell
dotnet run --project layout-checks/LayoutChecks.csproj -c Release
```

Эта команда запускается из корня архива, рядом с папками `DynamicIsland` и `layout-checks`.
Интерактивный запуск WPF и Win32 на реальном Windows при подготовке этой версии не выполнялся.
После запуска проверь переключение позиции двумя нажатиями, скрытие и возврат,
Ctrl-перетаскивание и режим полосы в развёрнутом браузере.

## Файлы изменений

- `MainWindow.Desktop.cs` — переключения, перетаскивание, видимость и жизненный цикл.
- `IslandSettings.cs` — настройки, запись JSON и расчёт положения.
- `SettingsWindow.xaml(.cs)` — окно настроек.
- `HotkeyManager.cs` — глобальные сочетания и проверка конфликтов.
- `ReservedStrip.cs` — резервирование верхней полосы через Windows AppBar.
- `TrayIcon.cs` — значок и меню в трее.
- `Native.Desktop.cs` — дополнительные вызовы Win32.
- В `MainWindow.xaml(.cs)` добавлены пункт настроек, обработчики перемещения и связь с новой логикой.

В исходном проекте использованы шрифты SF Pro; сведения автора о них сохранены в `Fonts/README.md`.
Все добавленные функции работают локально и не отправляют настройки или сочетания клавиш в сеть.
